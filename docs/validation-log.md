# 検証の記録

実際に試したことを、日付ごとに残す。新しいものを上に足す。
文言は [`wording-guide.md`](wording-guide.md) に従う（本人の気持ち・状態は書かず、観測したことを書く）。

書く形：

```
## YYYY-MM-DD 短い題
- **何を試したか**：端末・着け方・カメラ（広角／超広角）・普段の長さ・場面・時間
- **結果**：観測したこと（数値があれば数値。記録のファイル名があれば書く）
- **分かったこと**：結果から言えること
- **決めたこと**：変えたこと・変えないと決めたこと（理由つき）。まだ決めていなければ「なし」
```

## 2026-10-27 アプリの「いつもとの違い」を振り返りレポートの基準にそろえた
- **何を試したか**：撮る側の「いつもとの違い」の決まりを、振り返りレポート（`analysis/criteria.json`）と同じにした（`ios/AbilityCam/DiffEngine.swift`）。
  同じものをリプレイでも使う。作り物の記録1本と自分の記録3本で、Swift の判定と `review.py` の区間を比べた
- **結果**：4本とも、区間の数・指標・向き・開始と終了の時刻・ピークの z が一致した（作り物 5件、自分の記録 2件・0件・7件）
- **分かったこと**：アプリの画面・見る側・記録の `change` と、振り返りレポートの区間が、同じ決まりで出るようになった
- **決めたこと**：
  - ならし 0.3秒（前は約1秒）、|z| ≥ 2 が 0.5秒以上続いたら違い（前はすぐ）、|z| < 1.5 が 0.5秒続いたら終わり（前は 2 を下回ったらすぐ）
  - 表情は |yaw| < 35° のときだけ比べる（前は顔が読めるかだけ）
  - 目を細めるは、まばたき（eyeBlink 左右平均 0.3 以上と前後 0.2秒）のコマを使わず、普段にも数えない。後ろ 0.2秒を待つので、判定は約0.2秒遅れる
  - 声の大きさの標準偏差の下限を 2dB → 6dB
  - 表情の「いつもより弱い」は今までどおり出さない
  - `baseline` 行に `blink_masked: true` を書く（振り返りレポートは、この行の目を細めるを数え直さない）
  - このため、v1.0 からの `sessions.jsonl` の `segments`（違いが出た回数）は、前の版より少なく出る。前の記録とそのまま比べない

## 2026-10-27 わざと動かす記録（研究用の合計と、取れない表情の数値）
- **何を試したか**：わざと顔を動かす記録（自分の顔・3分37秒・顔が映っていた割合 88%）を、振り返りレポートで見た。何もしない記録とも比べた
- **結果**：
  - 研究用の合計は、眉を寄せる・目を細める・目を閉じる動きで 0.25〜0.91 まで上がり、何もしない記録の上位1%（0.21）よりはっきり高かった
  - cheekSquint と noseSneer は、何もしない記録・わざと動かす記録のどちらでも、ずっと 0 だった（鼻にしわを寄せても動かない）
  - mouthUpperUp は、声を出す・口を開ける動きで上がった
  - 撮り方の注意：普段の記録が終わる前に動いたため、普段に動きが混ざった。場面ボタンは1回しか押されていない
- **分かったこと**：MediaPipe では AU6（cheekSquint）・AU9（noseSneer）は取れない。mouthUpperUp は話す・口を開ける動きにも反応する
- **決めたこと**：
  - 研究用の合計から noseSneer と mouthUpperUp を外し、眉・目を細める・目を閉じるの3つにする（`criteria.json` の `research_composite.groups`。cheekSquint は max の中なのでそのまま残す）
  - 振り返りレポートの「記録の質」に、研究用の合計と指標に使っている表情の数値のうち、記録全体で最大値が 0.01 未満のものを「この記録では値が出ていません（MediaPipe が出していない可能性）」として出す

## 2026-10-27 顔の動きと状態の対応を調べた（文献）
- **何を試したか**：顔の動きと状態の対応について、文献を調べた
- **結果**：
  - 感情と顔の動きの 1対1 の対応はない（Barrett ほか 2019）
  - 痛みに関わる上半分の顔の動き（PSPI：AU4・AU6/7・AU9/10・AU43）が一番確かめられているが、痛みに限らず出る
  - 脳性麻痺では、何もしていないときも高めに出る
- **分かったこと**：上半分の顔の動きは、普段からの差で見る。口のまわりの動きは当てにしない
- **決めたこと**：
  - PSPI 型の合計を、研究用に振り返りレポートだけで計算し、家族には見せない（アプリ・見る側の画面には出さない。名前は「上半分の顔の動きの合計（PSPI 型・研究用）」で、区間の判定・通知候補には使わない）
  - 家族の印と照らし合わせて、意味があるかを確かめる
  - 「10分に1回以下」の目安は根拠がないため使わない（`--calm` では数字だけを出す）

## 2026-10-27 何もしない記録2本目（目を細める・声の大きさの区間が多い）
- **何を試したか**：何もしない記録（自分の顔・正面・3分55秒・顔が映っていた割合 96%・普段 30秒）を、振り返りレポートで見た。`--compare-baseline 30,60` でも比べた
- **結果**：
  - 区間 23件（10分あたり 約70件）。うち「目を細める」17件、「声の大きさ」5件
  - 30秒と60秒の比べは、10分あたり 72.5件／64.0件でほぼ同じ
  - 目を細める数値は、まばたきが多い時間帯ほど高い
  - 声の普段は -63dB で、10〜25dB の物音で区間になった
- **分かったこと**：目を細めるの区間には、まばたきが入っている。静かな部屋で普段を取ると、小さな物音でも声の大きさの区間になる
- **決めたこと**：
  - 目を細めるは、まばたきのコマを外す（eyeBlinkLeft/Right の平均が 0.3 以上のコマと前後 0.2秒は判定対象外、普段にも数えない。`criteria.json` の `eye_squint.blink_mask`）
  - 声の大きさの標準偏差の下限を 6dB にする（`criteria.json` の `std_floor.rms_db`）
  - どちらもまずレポートだけ変え、何もしない記録で効果を確かめてからアプリに揃える

## 2026-10-27 何もしない記録で、普段の長さ 30秒と60秒を比べる
- **何を試したか**：何もしない記録（自分の顔・正面・2分39秒・顔が映っていた割合 96%）を、振り返りレポートの `--compare-baseline 30,60` で比べた
- **結果**：
  - 区間は 30秒・60秒 ともに 8件（10分あたり 38.9件／51.5件。違いは判定した時間の長さによるもの）
  - 8件中7件が「目を細める」で、うち5件は「いつもより弱い」が 2.8〜12.5秒続いた（普段の平均 0.25 → 0.05〜0.10）
- **分かったこと**：普段の長さを 30秒にしても、60秒と比べて区間の数は変わらなかった。区間の多くは、表情の「いつもより弱い」方への変化だった
- **決めたこと**：
  - 普段の長さの初期値を 30秒にする（設定で 60秒も選べるまま）
  - 表情の「いつもより弱い」は、アプリと揃えて違いに数えない（振り返りレポートでは「表情の弱い方への変化（参考）」として別に出す。`criteria.json` の `face_below_counts: false`）
  - 開始・終了の基準（0.5秒など）は、何もしない記録が 3本以上たまるまで変えない

## 2026-10-27 胸ポケットで家族と会話（顔が外れる原因と、追える角度）
- **何を試したか**：iPhone を胸ポケットに入れ、背面カメラ・広角で、家族と会話した。あわせて、自分の顔で左右にどこまで向くと追えなくなるかを測った
- **結果**：
  - 会話では、顔が画面から外れることがあった
  - 自分の顔で測ると、左右およそ 50° までは追え、60° 弱で見えなくなる
- **分かったこと**：顔が外れる主な原因は、相手が顔を横に向けること。次いで、カメラの角度のずれ
- **決めたこと**：表情を「参考程度」にする基準（\|yaw\| が 35° を超えたら）は、そのままにする
