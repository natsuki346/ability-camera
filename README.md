# Ability Cam

介助者の胸に留めたスマホの背面カメラとマイクで、表情と声の変化をその場で解析する検証用アプリ。

## 確かめたいこと（根本の仮説）
- 映像から表情の変化を、音声の大きさ・高さから状態の変化を、読み取れるか
- それを即時に（撮影→結果の遅れが小さく）出せるか

画面に出る合格の目安：顔が映っている割合 / 解析コマ/秒 / 解析時間 / 撮影→結果の遅れ

## 原則
文言と色のルールは [`docs/wording-guide.md`](docs/wording-guide.md) が正。画面とレポートはこれに従う。

- 映像と音声は保存しない。外にも送らない（端末の中でその場で解析する）
- 記録（JSONL）にも、動画ファイルにも、リポジトリには入れない（`.gitignore` 済み）
- 医療機器にはしない。「気持ちが分かる」「痛みを検知」とは言わない

## 構成
- `ios/` … iOS アプリ（SwiftUI + MediaPipe Face Landmarker + AVAudioEngine）
- `web/` … ブラウザ版（録画ファイルの解析にも使える）
- `analysis/` … PC 用の振り返りレポート（記録から、普段から外れた区間を出す）。使い方は `analysis/README.md`

## iOS のビルド（Mac）
```sh
brew install xcodegen cocoapods
cd ios
TEAM_ID=あなたのチームID ./setup.sh   # モデルの取得 → xcodegen → pod install
open AbilityCam.xcworkspace           # .xcodeproj ではなくこちらを開く
```
iPhone をつないで実行。初回は、iPhone の 設定 > 一般 > VPNとデバイス管理 で開発元を信頼する。

## 画面（v0.2）
- **映り方の確認（v0.3）**：アプリを開くと（カメラの許可を得たら）すぐ映像が出て、網目・顔の絵・顔の向き・顔が映っている割合が動く。「開始」までは JSONL の記録・普段の記録・いつもとの違い・マイクは使わず、画面の上に「まだ記録していません（映り方の確認中）」と出す。「停止」しても映像は動いたまま（記録だけ止まる）。
  アプリが裏に回るとカメラを止め、前に戻ると再開する。記録していない間に操作がないまま5分たつとカメラを止め、「タップで再開」と出す
- **映り方チェック（v0.3）**：「開始」とは別のボタン。押すと計測を始め、もう一度押すと終える（アプリが裏に回ったら、そこで終える）。計測中は表情の記録・普段の記録・マイクを使わない。
  終えると、計測した時間・顔が映っていた時間（秒と割合）・顔が横を向きすぎていなかった時間（|yaw|<35°）・顔が映らなかった時間の一番長い続き・10秒ごとの顔が映っていた割合（棒グラフ）・解析コマ/秒の平均・撮影→網目の遅れの中央値を出す。
  **要約だけ**を「ファイル」アプリ > Ability Cam > `framing-checks.jsonl` に1行追記する（1コマごとの値・表情の数値・顔の点は書かない）。メモ（例「胸ポケット・姉・食事」）は終えたあとに付けられ、別の行として足す。振り返りは `analysis/framing.py`
- **いつもとの違い**：「開始」後の最初の60秒を「普段」として記録し（落ち着いているときに）、その後は各指標を約1秒でならした値が普段からどれだけ離れているかを出す（z =（今 − 普段の平均）÷ max(普段の標準偏差, 下限)、|z| ≥ 2）。
  出すのは「眉を寄せる動きが、いつもより強い」「声が、いつもより大きい／小さい／高い／低い」といった事実だけで、状態の名前（笑顔・痛み など）や点数は出さない。意味の解釈は家族がする。「普段を取り直す」でいつでもやり直せる
- **顔が読めません**：直近1秒で顔が見つかったコマが半分未満のときは、表情の違いを出さない（声の違いは出す）
- **家族の印**：快／不快／分からない。押した時刻が記録される（家族の判断を記録する言葉。アプリが本人の状態を言うのではない）
- **続いている秒数**：「眉を寄せる動きが、いつもより強い（12秒）」のように、違いが続いている秒数を出す
- **色**：赤と赤・黄・緑の組み合わせは使わない（停止ボタンも青灰）。音は鳴らさない
- **網目（v0.3）**：顔の478点を MediaPipe の接続（テッセレーション・輪郭・眉・目・唇）でつなぎ、映像に重ねる。眉＝アンバー（眉を寄せる）、目＝薄紫（目を細める）、唇の外側＝空色（口角を上げる）、内側＝青（口を開ける）で（色は `docs/wording-guide.md` の指標ごとの色と同じ）、その数値（0〜1）を線の濃さにしただけ。顔が読めないときは消す。右上のボタンでオン／オフ。
  網目は解析の遅れの分だけ映像より遅れて見える（隠さない）。その遅れは「撮影→網目 ms」に出る。点の座標は記録しない
- **配置（v0.3）**：画面の中心に大きく顔の絵、右上に小さくカメラ映像（網目つき、幅の1/3。タップで大きく、もう一度タップで戻る）。その下に「いつもとの違い」・家族の印・場面・数字・グラフ
- **顔の向き（v0.3）**：MediaPipe の変換行列から 左右（yaw）・上下（pitch）・傾き（roll）を度で求め、絵を同じ向きに動かす。絵の下に「顔の向き：右 25°・下 10°」（15°未満は出さず、どれも無ければ「正面」）。左右が35°を超えたら絵の表情部分を薄くし「横を向いているため表情は参考程度」と出す
- **顔の絵（v0.3）**：眉（眉頭・眉尻が別々）・上下のまぶたと瞳（視線は eyeLook*）・鼻（noseSneer）・上下の唇・あご（jawOpen）・耳をベジェ曲線で描いた顔が、blendshape の値（約0.2秒でならす）に比例して動く。色はやわらかい中間色で、数値によって色は変えない（長押しで 中間／明るめ／濃いめ／肌色なし を選べる）。左右は映像と同じ見え方（本人の左＝画面の右）。表情の名前・色・誇張は付けない。顔が読めないときは灰色・中立にして「読めません」とだけ出す。記録には何も足さない
- **場面**：食事／姿勢を変える／入浴・着替え／人が来た／その他。同時に一つだけ、もう一度押すと「場面なし」

## 記録の形式（`ability-cam.ios.v0.2`）
1行目はヘッダ（`schema`, `started_at`, `started_at_ms`, `device`, `ios`, `note`）。2行目からは1行1レコードで、`type` で種類を見分ける。すべての行に `t_ms`（epoch ms）がある。

### `type: "frame"`（1コマ1行）
| キー | 意味 |
|---|---|
| `t_ms` | 撮影時刻（epoch ms）。手首の記録（ability-lab.raw.v1）と並べるときに使う |
| `face` | 顔が見つかったか |
| `bs` | 表情の数値 52種（0〜1） |
| `pts` | 鍵となる顔の点（鼻先・額・あご・両目尻・両口角）[x, y, z] |
| `rms_db` / `f0_hz` | 音量 / 声の高さ |
| `yaw_deg` / `pitch_deg` / `roll_deg` | 顔の向き（度、v0.3〜）。映像で見て右を向く・上を向く・頭の上が右へ傾く が +。顔が無いコマには無い |
| `proc_ms` / `lat_ms` | 解析時間 / 撮影→結果の遅れ |

### 映り方チェック（`framing-checks.jsonl`、`ability-cam.framing.v1`）
ヘッダは無く、1行1レコード。
- `type: "framing_check"`：`id`, `started_ms` / `ended_ms`（epoch ms）, `duration_s`, `face_s` / `face_ratio`, `facing_s` / `facing_ratio`（顔が映っていて \|yaw\| < `yaw_limit_deg`）, `longest_no_face_s`, `bin_s`（10）, `bin_face_ratio`（10秒ごとの顔が映っていた割合の配列、コマが無い区切りは null）, `fps_mean`, `mesh_lag_ms_median`（網目を出していないときは無い）, `ended_by`（`button` / `background`）, `device`, `ios`
- `type: "framing_note"`：`id`（どのチェックか）, `t_ms`, `note`。同じ `id` に何度付けても、一番新しいものを使う

### `type: "baseline"`（普段を記録し終えたときに1行。取り直すたびに増える）
| キー | 意味 |
|---|---|
| `t_ms` / `started_ms` / `duration_s` | 記録し終えた時刻 / 記録し始めた時刻 / 長さ（秒） |
| `min_n` | 比べるのに必要なサンプル数（30） |
| `metrics` | 指標ごとの `{n, mean, std, insufficient}`。`insufficient: true` はデータ不足で、比べるのに使わない（n = 0 のときは mean / std なし） |

指標：`mouth_smile`（mouthSmileLeft/Right の平均）、`brow_down`（browDownLeft/Right）、`eye_squint`（eyeSquintLeft/Right）、`jaw_open`、`rms_db`、`f0_hz`（声があるときだけ）。std は標本標準偏差。

### `type: "event"`
| `kind` | `value` | 意味 |
|---|---|---|
| `scene` | 場面名 または `"なし"` | 場面のボタンを押した |
| `mark` | `"快"` / `"不快"` / `"分からない"` | 家族の印を押した |
| `change` | 違いの一覧（例 `["brow_down:above", "rms_db:below"]`、空なら違いなし） | 出ている違いの組み合わせ、または `face_readable`（顔が読めるか）が変わった。普段の記録が終わった直後に最初の1行 |
| `baseline_restart` | なし | 「普段を取り直す」を押した |

`t_ms` は押した（変わった）瞬間の時刻。
