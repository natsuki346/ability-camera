# 検証の記録

実際に試したことを、日付ごとに残す。新しいものを上に足す。
文言は [`wording-guide.md`](wording-guide.md) に従う（本人の気持ち・状態は書かず、観測したことを書く）。

書く形：

```
## YYYY-MM-DD 短い題
- **何を試したか**：端末・着け方・カメラ（広角／超広角）・普段の長さ・場面・時間
- **結果**：観測したこと（数値があれば数値。記録のファイル名があれば書く）
- **分かったこと**：結果から言えること
- **決めたこと**：変えたこと・変えないと決めたこと（理由つき）。まだ決めていなければ「なし」
```

## 2026-10-27 何もしない記録2本目（目を細める・声の大きさの区間が多い）
- **何を試したか**：何もしない記録（自分の顔・正面・3分55秒・顔が映っていた割合 96%・普段 30秒）を、振り返りレポートで見た。`--compare-baseline 30,60` でも比べた
- **結果**：
  - 区間 23件（10分あたり 約70件）。うち「目を細める」17件、「声の大きさ」5件
  - 30秒と60秒の比べは、10分あたり 72.5件／64.0件でほぼ同じ
  - 目を細める数値は、まばたきが多い時間帯ほど高い
  - 声の普段は -63dB で、10〜25dB の物音で区間になった
- **分かったこと**：目を細めるの区間には、まばたきが入っている。静かな部屋で普段を取ると、小さな物音でも声の大きさの区間になる
- **決めたこと**：
  - 目を細めるは、まばたきのコマを外す（eyeBlinkLeft/Right の平均が 0.3 以上のコマと前後 0.2秒は判定対象外、普段にも数えない。`criteria.json` の `eye_squint.blink_mask`）
  - 声の大きさの標準偏差の下限を 6dB にする（`criteria.json` の `std_floor.rms_db`）
  - どちらもまずレポートだけ変え、何もしない記録で効果を確かめてからアプリに揃える

## 2026-10-27 何もしない記録で、普段の長さ 30秒と60秒を比べる
- **何を試したか**：何もしない記録（自分の顔・正面・2分39秒・顔が映っていた割合 96%）を、振り返りレポートの `--compare-baseline 30,60` で比べた
- **結果**：
  - 区間は 30秒・60秒 ともに 8件（10分あたり 38.9件／51.5件。違いは判定した時間の長さによるもの）
  - 8件中7件が「目を細める」で、うち5件は「いつもより弱い」が 2.8〜12.5秒続いた（普段の平均 0.25 → 0.05〜0.10）
- **分かったこと**：普段の長さを 30秒にしても、60秒と比べて区間の数は変わらなかった。区間の多くは、表情の「いつもより弱い」方への変化だった
- **決めたこと**：
  - 普段の長さの初期値を 30秒にする（設定で 60秒も選べるまま）
  - 表情の「いつもより弱い」は、アプリと揃えて違いに数えない（振り返りレポートでは「表情の弱い方への変化（参考）」として別に出す。`criteria.json` の `face_below_counts: false`）
  - 開始・終了の基準（0.5秒など）は、何もしない記録が 3本以上たまるまで変えない

## 2026-10-27 胸ポケットで家族と会話（顔が外れる原因と、追える角度）
- **何を試したか**：iPhone を胸ポケットに入れ、背面カメラ・広角で、家族と会話した。あわせて、自分の顔で左右にどこまで向くと追えなくなるかを測った
- **結果**：
  - 会話では、顔が画面から外れることがあった
  - 自分の顔で測ると、左右およそ 50° までは追え、60° 弱で見えなくなる
- **分かったこと**：顔が外れる主な原因は、相手が顔を横に向けること。次いで、カメラの角度のずれ
- **決めたこと**：表情を「参考程度」にする基準（\|yaw\| が 35° を超えたら）は、そのままにする
