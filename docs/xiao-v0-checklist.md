# XIAO v0：届いた日の確認手順

上から順に進める。各ステップの「確かめること」がそろわなければ次に進まない。
結果は [`validation-log.md`](validation-log.md) にいちばん上へ足す（形は 5 の例）。

確かめたいのは2つだけ：①身につけて撮影・録音・送信が続けられるか ②平均消費電流。

---

## 0. 準備（部品が届く前にできる）

- [ ] Arduino IDE に Espressif の「esp32」ボードパッケージ（3.x）を入れる
- [ ] `firmware/xiao-cam/secrets.example.h` を `secrets.h` にコピーして書き換える（Wi-Fi は 2.4GHz、受信側の IP、`DEVICE_ID` は `xiao-01`）
- [ ] 受信側（Codex 担当）を Mac で動かし、`curl http://<受信側のIP>:8080/v0/time` で数字が返るのを確かめる
- [ ] 電流チェッカー・モバイルバッテリー・USB-C ケーブル（データ用。Mac への書き込みに使う）をそろえる

## 1. 書き込み

**電流チェッカーは外し、XIAO を Mac に直接つなぐ。**

1. カメラ基板（Sense の拡張ボード）を XIAO に付ける（アンテナも付ける）
2. Arduino IDE で `firmware/xiao-cam/xiao-cam.ino` を開く
3. ツール → ボード：**XIAO_ESP32S3**
4. ツール → PSRAM：**OPI PSRAM**（これを忘れるとカメラが動かない）
5. ツール → ポート：`/dev/cu.usbmodem…`
6. 書き込み

arduino-cli なら：

```sh
cd firmware/xiao-cam
arduino-cli compile --fqbn esp32:esp32:XIAO_ESP32S3:PSRAM=opi .
arduino-cli upload  --fqbn esp32:esp32:XIAO_ESP32S3:PSRAM=opi -p /dev/cu.usbmodem* .
```

書き込みが始まらないとき：BOOT ボタンを押したまま USB をつなぎ直し、もう一度書き込む。

## 2. シリアルで確かめる

シリアルモニタを 115200 で開き、RESET ボタンを押す。

```sh
arduino-cli monitor -p /dev/cu.usbmodem* -c baudrate=115200
```

確かめること：

- [ ] `[boot] Ability Cam XIAO v0` が出る。`PSRAM が無い` が出ない
- [ ] `[cam] 起動 PID=0x3660 (OV3660)` か `PID=0x5640 (OV5640)` が出る（どちらだったかを記録に書く）
- [ ] `[mic] 起動` が出る
- [ ] `[wifi] つながった ip=… rssi=…` が出る
- [ ] `[time] 合わせた offset=… 往復=… ms` が出る
- [ ] 10秒ごとに `[status] …` が出て、`time=ok cam=on mic=on`

## 3. 送れているか確かめる

モード1（`1` を入力）のまま、Mac につないだ状態で 2分ほど置く。

- [ ] `[status]` の `frame ok` と `audio ok` が 10秒で 10 前後ずつ増える
- [ ] `fail` と `drop` が増え続けない（起動直後の数個は時刻合わせ前なので出てよい）
- [ ] 受信側に静止画が届き、開くと映っている（640×480）
- [ ] 受信側に音声が届き、1つ 32,000 バイト。声を出した部分で波形が動く
- [ ] 受信側で `X-Seq` が抜けずに増えている
- [ ] `minheap` が 2分の間に下がり続けない

Wi-Fi が切れたときを確かめる：

- [ ] テザリング／ルーターを 30秒止めて戻す → `[wifi] 切れた` → `[wifi] つながった` が出て、`reconnect=1`。そのあと `ok` がまた増える

## 4. モードごとの平均消費電流

### やり方（1つのモードにつき）

1. Mac につないだまま、シリアルで測るモードの番号を入力する（`1`〜`4`）。本体が覚える
2. USB を Mac から抜く
3. **モバイルバッテリー → 電流チェッカー → USB-C ケーブル → XIAO** の順につなぐ
4. 本体の LED がモードの番号の回数だけ点滅するのを確かめる（例：モード3なら3回）
5. 電流チェッカーの積算（mAh）を 0 に戻し、時刻を書く
6. **30分以上**そのまま動かす（モード1は胸元に付けて、ふだんの動きをする）
7. 終わりの時刻と積算 mAh を書く
8. 受信側で、その間に届いた静止画・音声の数と `X-Seq` の抜けの数を書く（電池のときはシリアルが見えないため）

**平均電流（mA）＝ 積算 mAh ÷ 経過時間（時間）**
例：35分で 60 mAh なら 60 ÷ (35/60) ≒ 103 mA（計算の例。目標の値ではない）

### 測る順

| 順 | モード | シリアルで入力 | 胸元に付ける |
|---|---|---|---|
| 1 | ④ 待機（Wi-Fi 接続のみ） | `4` | どちらでもよい |
| 2 | ③ 音声のみ | `3` | どちらでもよい |
| 3 | ② 静止画のみ | `2` | どちらでもよい |
| 4 | ① 静止画＋音声 | `1` | **付ける**（確かめたいこと①） |

### 気をつけること

- モバイルバッテリーには、流れる電流が小さいと自動で切れるものがある。途中で止まっていないか、受信側に届き続けているかで確かめる
- 測っている間、Mac・受信側・Wi-Fi の場所は変えない（電波の強さで電流が変わりうる）
- モードの途中でつなぎ直したら、そのモードは最初から測り直す
