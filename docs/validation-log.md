# 検証の記録

実際に試したことを、日付ごとに残す。新しいものを上に足す。
文言は [`wording-guide.md`](wording-guide.md) に従う（本人の気持ち・状態は書かず、観測したことを書く）。

書く形：

```
## YYYY-MM-DD 短い題
- **何を試したか**：端末・着け方・カメラ（広角／超広角）・普段の長さ・場面・時間
- **結果**：観測したこと（数値があれば数値。記録のファイル名があれば書く）
- **分かったこと**：結果から言えること
- **決めたこと**：変えたこと・変えないと決めたこと（理由つき）。まだ決めていなければ「なし」
```

---

## 2026-10-27 胸ポケットで家族と会話（顔が外れる原因と、追える角度）
- **何を試したか**：iPhone を胸ポケットに入れ、背面カメラ・広角で、家族と会話した。あわせて、自分の顔で左右にどこまで向くと追えなくなるかを測った
- **結果**：
  - 会話では、顔が画面から外れることがあった
  - 自分の顔で測ると、左右およそ 50° までは追え、60° 弱で見えなくなる
- **分かったこと**：顔が外れる主な原因は、相手が顔を横に向けること。次いで、カメラの角度のずれ
- **決めたこと**：表情を「参考程度」にする基準（\|yaw\| が 35° を超えたら）は、そのままにする
