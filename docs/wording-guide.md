# 文言と色のガイド

アプリ（`ios/`）と振り返りレポート（`analysis/`）の画面・出力は、このガイドに従う。迷ったらこれが正。

## 1. 主語
- 主語は **観測された変化**（部位・指標の数値の動き）。
- 本人の気持ち・状態を主語にしない。「〜と感じている」「〜を訴えている」とは書かない。

## 2. 文の形
「**何が**（部位・指標）」「**どちらに**」「**どれだけ続いたか**」「**いつ**」を、分かるものだけ並べる。

| 要素 | 書き方 |
|---|---|
| 何が | 眉を寄せる動き／目を細める動き／口角を上げる動き／口を開ける動き／声の大きさ／声の高さ／目を閉じている／声が出た |
| どちらに | 表情：いつもより強い（／弱い）。声の大きさ：いつもより大きい／小さい。声の高さ：いつもより高い／低い。目を閉じている・声が出た：向きは無い（普段とは比べない） |
| どれだけ | 「（12秒）」のように秒数 |
| いつ | 「13:42:05」のように時刻 |

## 3. 使う語・使わない語
- **使う語**：変化、記録、確認、いつもの範囲、手がかり
- **使わない語**：不快、痛み、苦痛、異常、検知、緊急、危険、助けを求めて、要求している、安心してください、監視、見守り、患者
- **パーセントで変化を表さない**（「30%増加」など）。表情の数値は「いつもより強い」で表す。
  - 記録の質（顔が映っていた割合、判定対象外だった時間の割合など）は、変化ではないのでパーセントでよい。

### 本人の声（v1.6〜）
- 声の違いの言い方は今までどおり事実だけ：「声が、いつもより高い（4秒）」「声が、いつもより大きい」。気持ちの名前（「怒っている」「不安そう」「興奮している」など）は付けない。
- 本人の声と言えない声だけが入っているときは、小さく「**声：本人以外の声が入っています**」。違いには数えない。だれの声かは書かない（「介助する人の声」「家族の声」とは決めつけない）。
- 声の普段を集めている間は「**声の高さ：普段を集めています（本人の声 4/10秒）**」。「声が出ていません」「話してください」のように本人に求める言い方はしない。
- 声の普段の進み具合が増えないときの理由（v1.6.2〜）は、事実だけを小さく：「**声の普段が増えない理由：声の高さが取れていません**」「**口が動いていません**」「**顔が読めていません**」。
  「もっと大きな声で」「近づけてください」のように本人や介助する人に求める言い方はしない。
- 「数字」の「声の高さが取れた割合」は記録の質なのでパーセントでよい。
- 声の普段を取り直している間（v1.9.3〜）は「声の普段を集め直しています。この間は口の動きだけで本人の声を数えます」。どう数えているかの事実だけで、本人に声を出すよう求めない。
- 声の普段が増えない理由（v1.9〜）に「口の動きと声のタイミングが合っていません」「声の高さが本人の普段の範囲の外です」を足す。だれの声かは書かない（「介助する人の声です」とは言わない）。
- 本人の声の見分けは声の高さとタイミングだけで行い、声紋（声の特徴で人を特定するもの）は作らない。「〇〇さんの声と判定」のような言い方はしない。
- 振り返りレポートでは「本人の声の時間」「本人の声と言えない声の時間」と書く（口が動いていない声は、本人の声かどうか分からないため「本人以外の声」と言い切らない）。

### 声が出た（v1.7〜）
- 画面・記録の文は「**声が出た（2秒）**」だけ。普段とは比べないので「いつもより」は付けない。秒数は声のまとまりの最初から数える。
- 気持ち・状態の名前を付けない。「話しかけた」「訴えた」「うめいた」「呼んだ」「返事をした」「叫んだ」「喜んで声を出した」などとは書かない（声が何を意味するかはアプリには分からない）。
- 「声を出してくれた」「声が出せた」のように、良い・悪いを付けた言い方もしない。
- 見る側の「いま」では「声が出た（2秒）」／「出ていない」。振り返りレポートでは「声が出た ○回、長さの合計 ○秒」「家族の印の前10秒に声が：出ていた（1.2秒）／出ていない」。
- いつもとの違いではないので、「違いが出た回数」には数えない。

### だれの声か（話者の区別、v1.10〜）
- v1.10 は記録に書くだけで、画面には出さない。出すときの言い方は「〇〇の声（4秒）」「だれの声か分からない声」だけ（`docs/speaker-plan.md`）。
- 「〇〇さんと判定」「本人と確認」「声紋」「認証」「話しかけた」「呼んだ」とは書かない。似ている度合いは記録の質としてだけ数字で出す（「一致率」とは言わない）。
- 登録の画面では「声の特徴を数値にして、この端末の中だけに保存します」「本人確認には使いません」と、何をするかを先に書き、同意した人の名前を聞く。
- 登録している間の撮る側の「いま」（v1.10.1〜）：「〇〇の声を集めています（12/15秒）。黙っている間は数えません」（分母は登録に必要な秒数。v1.10.4〜 15秒）。たまったら「〇〇の声を登録しました」（取り直しは「〇〇の声を登録し直しました」）。
- 登録の画面に、どちらで集めるかを事実だけ小さく出す（v1.10.1〜）：「選んでいる人なので、本人の声として数えた時間だけを集めます」／「選んでいる人ではないので、声が出ている時間をすべて集めます」。
  「本人と判定された声」「認識」とは書かない（「本人の声を数えます」と同じ言い方）。
- 設定「話者の区別を記録する」のトグルの下（v1.10.2〜）：「切り替えは次の記録から効きます」。記録中は「切り替えは次の記録から効きます。今の記録はオン（オフ）のままです」。
- テレビ・動画の声は「テレビの声」「動画の声」とは書かない（アプリには分からない）。登録した人のだれとも似ていない声は「だれの声か分からない声」（画面に出すとき）。

### 目を閉じている（v1.4〜）
- 画面・記録の文は「**目を閉じている（4秒）**」だけ。普段とは比べないので「いつもより」は付けない。続いた秒数は閉じ始めた時刻から数える。
- 状態の名前を付けない。「眠っている」「眠そう」「うとうと」「意識がない」「痛くて目をつぶっている」などとは書かない（目を閉じている理由はアプリには分からない）。
- 0.5秒より短いものは「まばたき」として数えない（画面にも出さない）。
- 見る側の「いま」では「閉じている（4秒）」／「閉じていない」。振り返りレポートの向きの欄は「閉じている」。

### 研究用の値の名前
振り返りレポートの研究用の値（上半分の顔の動きを合わせたもの）は「**上半分の顔の動きの合計（PSPI 型・研究用）**」と呼ぶ。
もとの尺度が痛みの評価に使われるものでも、レポートでは「痛み」という言葉を使わない。区間の判定・通知候補には使わず、アプリ・見る側の画面には出さない。

### 例外：家族の印
家族の印のボタン「快／不快／分からない」は、**家族が自分の判断を記録するための言葉**で、アプリやレポートが本人の状態を言っているのではない。
そのため、印の名前としてだけ使ってよい（記録の `value` もそのまま）。印の名前以外の文では使わない。
レポートでは「家族の印：不快」のように、必ず「家族の印」と分かる形で出す。

## 4. 例文と禁止例

| 良い例 | 使わない例 | 理由 |
|---|---|---|
| 眉を寄せる動きが、いつもより強い（12秒） | 不快そうです | 気持ちを主語にしている |
| 声が、いつもより高い（13:42:05〜、8秒） | 痛みを検知しました | 状態の名前・「検知」 |
| 口を開ける動きが、いつもより強い | 口の開きが30%増加 | パーセントで変化を表している |
| 目を閉じている（4秒） | 眠っています／眠そうです | 状態の名前を付けている |
| 声が出た（2秒） | 何かを訴えています／声を出してくれました | 意味や良い・悪いを付けている |
| いつもと大きな違いはありません | 異常はありません／安心してください | 「異常」「安心してください」 |
| 変化の区間が 3件 記録されました | 緊急：助けを求めています | 「緊急」「助けを求めて」 |
| 通知候補（実際には通知しない） | 危険アラート | 「危険」 |
| 記録を確認するための手がかりです | 見守り・監視のためのアプリです | 「見守り」「監視」 |
| 本人 | 患者 | 「患者」 |

## 5. 色
- **赤は使わない。** 赤・黄・緑の組み合わせ（信号の色）も使わない（良い・悪いに見えるため）。
- **いつもの範囲**：薄い青灰の帯（例 `#DCE3EA`）。
- **今の値**：濃紺（例 `#1F3A5F`）か、アンバー（例 `#E69F00`）の線。
- 区間の塗り：いつもより上＝アンバーの薄い塗り、いつもより下＝青灰（例 `#5B7FA6`）の薄い塗り。
- 指標ごとの色（グラフ・網目で同じ）：

  | 指標 | 色 |
  |---|---|
  | 口角を上げる | 空色 `#56B4E9` |
  | 眉を寄せる | アンバー `#E69F00` |
  | 目を細める | 薄紫 `#A48CD1` |
  | 口を開ける | 青 `#3B78C2` |
  | 声の大きさ | 灰茶 `#9C8572` |
  | 声の高さ | 赤紫 `#CC79A7` |
  | 目を閉じている | 墨紫 `#5E4B8B`（目を細めるの薄紫より濃い。閉じていた時間の塗りにだけ使い、メーターは無い） |

  | 声が出た | 焦げ茶 `#6B4E3D`（声の大きさの灰茶より濃い。声が出ていた時間の塗りにだけ使い、メーターは無い、v1.7〜） |

  目を閉じている・声が出たの色は、その事実だけを塗る色なので、アンバー（いつもより上）や青灰（いつもより下）とは別にした。
  撮る側のグラフでは薄い帯（不透明度 0.22）、見る側の時間の流れ・リプレイの段・振り返りレポートの時系列では区間と同じ濃さで塗る。

- 顔の向きの段（見る側の時間の流れ・振り返りレポート）：向きの事実だけなので、良い・悪いに見えない色で塗る。

  | 向き | 色 |
  |---|---|
  | 正面 | 薄い青灰 `#DCE3EA` |
  | 右 | 青灰 `#5B7FA6` |
  | 左 | 砂色 `#B8A07A` |
  | 見えない | 灰 `#7D848C` |
  | 斜め（見えなくなったあと 15〜35°） | 薄い藤色 `#C9C4D9` |

  記録の文は「右へ」「正面に戻った」「見えなくなった（直前は右 40°）」のように、向きと角度だけを書く（「そむけた＝嫌がっている」のように意味を付けない）。

- **顔の向きの普段との違い**（v1.8〜、振り返りレポートだけ）は「いつもより右に傾いていた 13:42:05〜、12秒（本人から見て）」「いつもより下を向いていた」のように、向きと時刻と秒数だけ。
  「そむけた」「嫌がった」「疲れている」「うなだれていた」「眠そう」など、向きに意味や状態を付けない。「急な向きの変化」も、何回あったかと時刻だけ（「驚いた」「びくっとした」とは書かない）。
- **右・左は、本人から見た右・左**（v1.7.1〜）。向かい合って見る人から見た右ではない。前面でも背面でも、本人が自分の右へ向く・傾けると「右」。表情の Left / Right（本人の側）とも揃える。
  画面に右・左を出すときは、どちらから見た右か分かるように「（本人から見て）」を付ける：「顔の向き：右 25°（本人から見て）」「右（本人から見て、35°超）」。
  1つの画面に何度も出るとき（記録の一覧など）は、見出しに1回「右・左は本人から見て」と書けばよい。「画面の右」「映像の右」のような言い方は使わない
- 停止など操作のボタンも赤にしない（中間色の青灰）。
- 顔の絵は、数値によって色を変えない（頬を赤くする・顔色を変える等をしない）。

### 文字の色と大きさ（撮る側・見る側の「いま」、v1.10.5〜。`ios/AbilityCam/Theme.swift` の `Palette`）
文字を種類ごとに色で分け、大事なもの（いつもとの違い）と補足（進み具合・理由）を大きさ・太さで分ける。色は種類を見分けるためだけに使い、良い・悪いは表さない（赤・黄・緑は使わない）。
文字の色はメーターの点の色の仲間で、白の背景で 6.9:1 以上・黒の背景で 11:1 以上になる濃さ（ダークモードでは明るい色に替える）。
メーターの点の色（空色・アンバーなど）は白の上で文字にすると薄いので、文字にはせず、行の頭の小さな印（縁取りつき）にだけ使う。

| 種類 | 文字の色（ライト / ダーク） | 行の頭 | 大きさ・太さ | 例 |
|---|---|---|---|---|
| 表情の違い（大事） | 濃紺 `#1F3A5F` / `#DCE3EA` | その指標のメーターの点の色の印 | いちばん大きく太く（撮る側 title3 太字、見る側 28pt 太字） | 「● 眉を寄せる動きが、いつもより強い（4秒）」 |
| 目を閉じている（大事） | 墨紫 `#5E4B8B` / `#C9BCE8` | 墨紫の印（ダークは `#9B87C9`） | 同じ | 「● 目を閉じている（3秒）」 |
| 声の違い・声が出た（大事） | 焦げ茶 `#6B4E3D` / `#E3CDB9` | 声の大きさ・声の高さの点の色の印（声が出たは焦げ茶、ダークは `#A8876F`） | 同じ | 「● 声が、いつもより大きい（2秒）」 |
| 声の補足（本人以外の声・声の普段のばらつき） | 焦げ茶 `#6B4E3D` / `#E3CDB9` | `waveform` | 小さく（caption）、本人以外の声は少し太く | 「声：本人以外の声が入っています」 |
| 顔の向き | 藍 `#2F5D8A` / `#A9C8E8` | なし | 小さく、少し太く | 「顔の向き：右 24°（本人から見て）」 |
| 進み具合（普段・声の普段・声の登録） | 青灰 `#4F5B6B` / `#C2CAD4` | `hourglass`・`person.wave.2`・`arrow.clockwise` | 小さく（caption）。普段を記録している間の見出しだけ大きく | 「声の高さ：普段を集めています（本人の声 6/10秒）」 |
| 進まない理由 | 青灰（同じ） | `info.circle` | いちばん小さく（caption2） | 「声の普段が増えない理由：口が動いていません」 |
| 記録の状態 | 濃紺（同じ） | `record.circle` | 小さく | 「顔：読めています・普段：記録しました」 |

- 目を閉じていた時間が長い（普段の間）は墨紫・`eye.slash`。違いが無いときの「いつもと大きな違いはありません」は濃紺で、違いより少し細く（semibold）。
- 状態の名前（「眠そう」「嫌がっている」など）は、色やアイコンでも表さない。アイコンは何の話か（声・時間・目）を示すだけ。
- 変える前と後：`docs/screenshots/now-before_light.png`・`now-after_light.png`（ダークモードは `_dark`）。シミュレーターで、Debug ビルドの起動引数 `-role camera -uiPreview`（作り物の値を入れて、カメラ・記録は動かさない）で撮った

## 6. 音
- 既定は無音。
- 本人の前で音を鳴らす機能は作らない。
